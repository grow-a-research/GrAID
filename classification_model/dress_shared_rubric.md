# Shared rubric — DREsS_New multi-rater subset

Used only for the 15-essay shared batch that all 5 professors grade in common
(for the descriptive inter-rater agreement stat). Professors' own subject
essays (125 total, 25 each) still use each professor's own rubric —
unchanged.

Source: adapted from DREsS's own 3-criterion rubric (Yoo et al., "DREsS:
Dataset for Rubric-based Essay Scoring on EFL Writing", ACL 2025, Table 2).
DREsS's paper only publishes a holistic top-level description per criterion
(no per-level anchors) — the 1-4 level descriptions below are a GrAId-team
extrapolation, not an official DREsS document. **Not yet validated with the
professors.** Recommend a short norming pass (all 5 professors score the
same 1-2 sample essays together and discuss) before grading the real 15,
matching the norming approach DREsS's own annotators used.

Scale: 1.0-5.0 per criterion, 0.5 increments allowed between levels.
Total = Content + Organization + Language (max 15).

## Content — relevance & development of the argument

| Score | Description |
|---|---|
| 5 | Well-developed, clearly relevant argument; strong, specific reasons and examples throughout |
| 4 | Mostly developed and relevant; reasons/examples present but under-elaborated in places |
| 3 | Argument present but development is inconsistent; some reasons/examples generic or thin |
| 2 | Argument unclear or weakly related to the prompt; few or unconvincing supporting reasons/examples |
| 1 | Little to no relevant argument; supporting reasons/examples missing or off-topic |

## Organization — structure & coherence

| Score | Description |
|---|---|
| 5 | Very effective structure, easy to follow, strong coherence devices, one main idea per paragraph |
| 4 | Generally well-structured and easy to follow; minor coherence or paragraph-focus lapses |
| 3 | Structure discernible but uneven; some ideas hard to follow or paragraphs mix multiple ideas |
| 2 | Weak structure; confusing sequencing of ideas; coherence devices rare or misused |
| 1 | Little discernible structure; ideas appear disconnected or randomly ordered |

## Language — vocabulary, grammar, spelling, punctuation

| Score | Description |
|---|---|
| 5 | Sophisticated, varied vocabulary and collocations; grammar/spelling/punctuation correct throughout |
| 4 | Good vocabulary range; occasional minor errors that don't impede understanding |
| 3 | Adequate vocabulary; noticeable errors, occasionally distracting |
| 2 | Limited vocabulary; frequent errors that sometimes obscure meaning |
| 1 | Very limited vocabulary; pervasive errors that significantly impede understanding |
